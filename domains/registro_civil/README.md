# Dominio: registro civil

## Objetivo

Distinguir copia, aclaración y corrección de acta con el mínimo de preguntas.

## Contenido

Ejemplos: `domain.yaml`, `decision_rules.yaml`, prompts, fuentes, fixtures y tools de oficialías/disponibilidad.

## Exclusiones

No resolver disputas jurídicas ni modificar actas reales.

## Convenciones y dependencias

Preguntar únicamente el dato que diferencie procedimientos igualmente probables. Depende de RAG y tools autorizadas de registro civil.

Responsable: Diego.

## Tareas iniciales

Crear fuentes, regla de clasificación, localización de oficialía y solicitud simulada.

## Terminado

`CAP-RC-01` no mezcla procedimientos, muestra requisitos/costos/tiempos citados y formula como máximo la pregunta indispensable.
