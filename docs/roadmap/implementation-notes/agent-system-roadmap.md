# Roadmap del sistema inteligente

| Fase | Capacidades |
| --- | --- |
| MVP | Grafo secuencial, clasificación, navegación, RAG, verificación, estimación, confirmación y redacción |
| Core | Catálogo central, cinco dominios, fuentes versionadas, evaluación y replay |
| Pro | Router de modelos, MCP Mapper, voz y adaptadores externos |
| Extremo | Paralelismo, contradicciones, mini-RAGs, judge y actualización de corpus |

La compatibilidad se protege mediante schemas, fixtures, puertos y pruebas de
contrato. Las integraciones externas se mantienen detrás de adapters.
