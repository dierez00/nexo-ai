# Roadmap de frontend

La evolución del frontend se organiza por superficies y contratos consumidos.

| Fase | Entregable |
| --- | --- |
| MVP | Portal, login, chat, citas, seguimiento, admin básico y A2UI ciudadano |
| Core | Workflow reproducible, catálogo central, métricas y estados operativos |
| Pro | Formularios dinámicos, voz, integraciones de canal y administración A2UI |
| Extremo | Builder visual, personalización y analítica avanzada |

Cada entrega debe incluir estados de error y carga, accesibilidad, pruebas de
contrato y fallback seguro.
