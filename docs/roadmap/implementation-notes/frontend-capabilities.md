# Capacidades de frontend

La aplicación web concentra portal ciudadano, administración, chat, workflow y
renderer A2UI en una sola superficie Next.js.

## Implementado

- Rutas públicas, login, portal y administración protegida por rol.
- Chat con conversaciones, runs y SSE.
- Estados de carga, vacío, error, parcialidad y confirmación.
- Renderer A2UI con catálogo cerrado, validación y fallback.
- Vistas de catálogo, integraciones, runs, workflow y laboratorio A2UI.

## Roadmap

- Completar pruebas de navegador y accesibilidad.
- Sustituir fixtures de fallback donde exista endpoint operativo.
- Generar cliente TypeScript desde OpenAPI.
- Añadir formularios A2UI dinámicos y superficies administrativas verificadas.
