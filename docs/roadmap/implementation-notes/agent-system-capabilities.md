# Sistema de agentes

El núcleo inteligente incluye clasificación, navegación por dominio,
verificación, estimación determinista, ejecución transaccional y redacción.
RAG y MCP se consumen mediante puertos y contratos.

## Estado

- Agentes transversales implementados con salidas tipadas.
- Corpus versionado y retrieval híbrido disponibles offline.
- Herramientas MCP registradas, autorizadas y ejecutables con dobles.
- A2UI se construye desde hechos verificados y catálogo cerrado.

## Evolución

Router de modelos productivo, MCP Mapper, adaptadores reales, ejecución
paralela, mini-RAGs, personalización y evaluación con juez.
