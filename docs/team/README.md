## Convenciones

Actualizar checklists en la planeación de cada fase; no usar estos archivos como sustituto de issues. Las responsabilidades compartidas deben declarar principal, apoyo, contrato y momento de integración.

## Exclusiones

No incluir evaluaciones personales, secretos ni compromisos sin dependencia explícita.

Responsable: cada integrante mantiene su archivo; el equipo revisa al cierre de fase.

Terminado cuando todas las tareas activas tienen entregable, aceptación, dependencia y owner inequívocos.
