# Código abierto

Nexo IA se distribuye bajo la [licencia MIT](../../LICENSE). La licencia cubre
el código y la documentación del proyecto salvo que un archivo indique otra
condición.

Antes de redistribuir corpus, assets, fixtures o integraciones de terceros,
verifica su procedencia y las condiciones específicas indicadas junto al
recurso. No se deben incluir secretos, credenciales ni PII real en commits,
issues o contribuciones.

Las contribuciones deben conservar los contratos versionados, mantener las
pruebas del área afectada y actualizar la documentación cuando cambien rutas,
configuración o comportamiento público.
