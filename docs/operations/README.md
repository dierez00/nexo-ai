# Operaciones

Esta sección reúne procedimientos de mantenimiento que afectan a más de un
módulo y no pertenecen a un proveedor concreto.

Documenta aquí únicamente procesos repetibles: verificación de despliegues,
rotación de configuración, recuperación, revisión de documentación y criterios
de soporte. Los runbooks específicos permanecen en [`../runbooks/`](../runbooks/).
