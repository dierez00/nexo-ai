# Assets de demostración

Contiene imágenes, documentos de muestra y recursos visuales usados por portal o presentación.

Cada asset debe declarar autor/origen/licencia y propósito.

## Exclusiones

No incluir PII, logos sin permiso ni binarios generados que puedan reconstruirse en build.

Convención: nombre descriptivo, formato optimizado y alternativa accesible cuando se renderice.

Responsable: Cris.

Dependencias permitidas: `apps/web` y documentación pueden leerlos; ningún backend debe tratarlos como storage operativo. Ejemplos: `demo-license.pdf` e `images/portal-placeholder.webp`.

Tareas: documentos de carga sintéticos, imágenes de demo y manifest de licencias. Terminado cuando todos los assets tienen procedencia, tamaño razonable y uso referenciado.
